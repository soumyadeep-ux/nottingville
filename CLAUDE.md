# Nottingville — Girls' Hostel Website

Single static HTML page. No framework, no build step. Just index.html + images/.

## Deploy
**NEVER deploy `.` directly** — MP4/video files in the repo root break Cloudflare Pages (emoji filenames cause 404s for all URLs with query params like `?fbclid=`).

```bash
# Clean deploy: copy only site files to temp dir, deploy that
# NOTE: `cp *.html` now picks up index.html AND the 8 landing pages.
# _headers and assets/ MUST be copied or caching + LP styling silently break.
mkdir -p /tmp/nottingville-deploy/images /tmp/nottingville-deploy/assets && \
  cp *.html robots.txt sitemap.xml _headers favicon.svg favicon-32x32.png apple-touch-icon.png /tmp/nottingville-deploy/ && \
  cp assets/lp.css assets/lp.js /tmp/nottingville-deploy/assets/ && \
  cp images/hostel-*.jpg images/hostel-*.webp /tmp/nottingville-deploy/images/ 2>/dev/null; \
  npx wrangler pages deploy /tmp/nottingville-deploy --project-name nottingville --commit-dirty=true && \
  rm -rf /tmp/nottingville-deploy

git push origin main
```
Wrangler OAuth already configured. If it expires: `npx wrangler login`

**Positioning: food first, on every page.** Verified facts only: 4 meals daily,
non-veg 6 days a week, included in rent, "Home like Food" is a real Google review
quote. Rating 4.6 from 17 Google reviews is displayed but deliberately NOT marked
up as `aggregateRating` — those reviews live on Google, and self-marking
third-party reviews breaches Google's structured-data policy.

**LPs do NOT use the lead-capture modal.** `index.html` intercepts every WhatsApp
click and forces a 7-field form; that gate is why WhatsApp logged 6 conversions in
90 days against 29 on-page entry points, while ungated `tel:` clicks logged 16.
`assets/lp.js` lets WhatsApp links open directly and bakes the qualifying context
into a per-page prefilled message instead. The enquiry is still logged to the
Google Sheet via a non-blocking pixel.

Each prefilled message ends with `Ref: <page-slug>`, so the owners see the source
ad group next to the sender's number in the WhatsApp inbox without touching the
sheet. Deliberately the slug and not the gclid — a tracking string in a message a
parent reads looks like spam. Note this only reaches you if they actually tap
**send**; silent openers still fire the Ads conversion and still write a sheet row,
which is why real chats always run below the WhatsApp Click count.

**Open items for the owners:** exact AC / Non-AC / sharing tariff (the table has a
marked slot; deliberately not guessed), and whether a mess-only service is sold
(5 mess keywords are live with no page).

## Gotchas
- **CRITICAL: Never `wrangler pages deploy .`** — MP4 files with emoji filenames in repo root corrupt the deployment. All URLs with query params (`?fbclid=`, `?utm_source=`) return 404. Site appears to work because Cloudflare edge cache serves stale root `/` but ad traffic (which always has `?fbclid=`) breaks. Use the clean deploy command above.
- Domain was WHOIS-suspended on first deploy — always verify registrant email before DNS changes
- Cloudflare Pages UI GitHub connect had redirect loop bug — use wrangler CLI instead
- Hero text cut off on mobile — fixed via `padding-top: 5rem` on `.hero`
- Wrangler: create project first if new: `npx wrangler pages project create nottingville --production-branch main`
- gh CLI authenticated as `soumyadeep-ux` (keyring, no token needed)
- Cloudflare DNS nameservers: `ainsley.ns.cloudflare.com`, `kobe.ns.cloudflare.com`
- **`/assets/*` is served `max-age=31536000, immutable`** (see `_headers`). `immutable` means browsers do not even revalidate, so a stable filename would pin `lp.js`/`lp.css` in a returning visitor's browser for a year — no edit could ever reach them. `build-lp.py` therefore appends a content hash (`/assets/lp.js?v=<md5-8>`) via `asset_url()`. Filenames stay stable, so the deploy command above is unaffected. Never hand-write `/assets/lp.js` into a template without the version.
- HTML is `max-age=0, must-revalidate` / `cf-cache-status: DYNAMIC` — Cloudflare Pages does not edge-cache HTML documents. So an asset version bump reaches every visitor on their next page view, with no purge needed.
